# Équipe d'agents

Agents (`.claude/agents/`) : chef-de-projet, developpeur, testeur, conseiller, designer, securite, base-de-donnees.
Règles communes : `REGLES.md`. Chaque agent écrit son rapport ici ; le chef écrit `COMPTE_RENDU.md` et `TACHES.md`.
Aucune fusion de PR sans accord de la personne qui pilote.
