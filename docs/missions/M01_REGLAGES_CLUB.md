# M01 — Catalogue des réglages observés

Annexe du [contrat M01](M01_CONTRAT_FONCTIONNEL.md). Lecture seule le 15 novembre 2026 ; publiée le 16. Source : définition IMMUTABLE de private.club_rule_catalogue(), puis SELECT du catalogue commercial. Ce sont les **défauts et bornes**, pas les valeurs propres à chaque équipe. Aucun réglage changé.

66 clés, dont waitlist_cutoff_days et waitlist_cutoff_hour cachées par ClubSettingsPage et sans attribution automatique à promettre. Sept modules parents existent dans ClubModule. Gestion sportive permanente.

Pour chaque clé : identifiant stable = REG-<clé>. Responsable réalisation M02, recette M03. Scénario proposé = REC-REG-<clé> : admin sauvegarde borne basse/haute, valeur hors borne refusée, null revient au défaut ; membre/autre espace ne modifie pas le réglage ; relecture et second appareil cohérents ; vérification de l'effet métier décrit, parents OFF et historique préservé. **Scénarios non exécutés par M01**. Tests à rapprocher : club_feature_extension.test.sql, club_feature_settings.test.sql, club_rules.test.sql, live_feature_rules.test.sql, club_settings_page_test.dart. Le passage d'un test de catalogue ne prouve pas chaque effet métier.
